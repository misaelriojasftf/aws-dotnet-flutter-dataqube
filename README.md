# 🚀 AWS + .NET & Flutter Workshop

Welcome! This repository contains all the resources, labs, and projects from our AWS + .NET & Flutter Workshop.
Whether you’re building serverless backends with .NET or mobile apps with Flutter, this repo has you covered.

## 📂 Repository Structure

We’ve organized the repo to separate backend and mobile code for clarity:

```
backend/       # .NET serverless projects, Lambdas, APIs, RDS integrations
mobile/        # Flutter apps and AWS-integrated clients
```

## 🛠 Technologies Covered
- AWS Services: Lambda, API Gateway, DynamoDB, RDS, S3, Cognito, Amplify, Pinpoint, CloudWatch, STS
- Backend: .NET 8, C#, Serilog, Serverless Architecture
- Mobile: Flutter, Hive, AWS SDK integration
- DevOps & CI/CD: GitHub Actions, SAM/CDK, Deployment Pipelines


## 💡 Tips for Success
- Keep your AWS credentials and region configuration ready.
- Use logging and metrics to debug and monitor Lambdas.
- Try extending APIs and connecting them to mobile apps for hands-on experience.
- Experiment with CI/CD pipelines to deploy serverless projects effortlessly.
